At a Glance

Objectives

  • Give the team one place to find everything about a CABAL project instead of hunting across Drive, Canva, and chat threads
  • Preserve institutional knowledge as campaigns wrap and people rotate off them
  • Cut the time to compile a project's key facts for planning or handoff from hours to minutes
  • Feed Northstar's strategy layer with clean, structured, current source material

Features

  • Multi-format ingestion: Google Docs, Sheets, Canva slide decks, CSVs, plain text, images
  • Automatic key-fact extraction and summarization per source
  • Categorization by CABAL project and content type — rules first, AI fallback flagged for review
  • Structured Obsidian notes queryable as a database via Bases/Dataview, no separate database engine
  • Dedupe and update-in-place instead of duplicate notes for the same source
  • A Needs Review view that surfaces anything AI-categorized before it's trusted

Flow

flowchart LR A[Inbox: drop file/link] --> B[Fetch and Parse] B --> C[Extract key info] C --> D{Rule match?} D -- Yes --> E[Categorize: rule] D -- No --> F[Categorize: AI fallback / needs-review] E --> G[Write note to vault] F --> G G --> H{Existing note?} H -- Yes --> I[Update in place] H -- No --> J[Create new note] I --> K[Vault views] J --> K
